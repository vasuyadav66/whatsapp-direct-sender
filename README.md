# DirectChat — Multi-Platform Direct Sender with Identity, Date & Time 💬

Direct message sender for **WhatsApp, Instagram, Snapchat, Facebook Messenger, and SMS** with automatic sender signature **`star66`**, live **Date & Time** timestamp, and **Instant QR Code** without needing to save contacts.

## 🚀 Supported Platforms & Direct Sending

| Platform | Input | Direct Action |
| :--- | :--- | :--- |
| 🟢 **WhatsApp** | Phone Number | Opens chat on WhatsApp Web/App with message signed as `star66` + timestamp |
| 📸 **Instagram** | Username / ID | Copies message signed as `star66` + timestamp & opens Instagram DM (`ig.me/m/<user>`) |
| 👻 **Snapchat** | Username | Copies message signed as `star66` + timestamp & opens Snapchat (`snapchat.com/add/<user>`) |
| 🔵 **Messenger** | Facebook ID / Username | Copies message signed as `star66` + timestamp & opens Messenger (`m.me/<user>`) |
| ✉️ **Normal SMS** | Phone Number | Launches native SMS app with message prefilled with `star66` + timestamp |

## 🌟 Key Features

1. **Identity `star66` + Date & Time**:
   - Automatically attaches sender tag and timestamp:
     `— Sent by star66 • 27 Oct 2026, 06:40 PM`
   - Real-time preview showing exactly what the recipient sees.
   - Individual checkboxes to toggle Name and Date/Time on/off.
2. **Instant QR Code Generation**:
   - **Website QR**: Scan the on-screen QR code from any mobile device to open DirectChat instantly.
   - **Chat QR**: Generate an instant QR code for any WhatsApp or SMS conversation to jump straight to mobile chat from a desktop.
3. **Live Clock**:
   - Header displays a live local clock that ticks in real time.
   - "Insert Timestamp" button in preset chips to insert the current date/time anywhere in the message.
4. **Dynamic UI**:
   - Switches automatically between international phone number input (with country flag selector) and social handle `@username` input.
5. **Convenience Tools**:
   - One-click copy message with `star66` signature & timestamp.
   - One-click copy direct link.
   - Recents history showing sent date, time, and platform.
